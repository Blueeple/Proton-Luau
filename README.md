## Built along side the EZFramework.

The EZFramework is Roblox development framework that is heavily specialized in Fast Paced, FPS, Open World and Racing games. Build for optimization and cross-platform compatibility with Desktop, Console and Mobile with possible VR support in the future. The Goal of EZFramework is to allow the development of Large Complex FPS, OpenWorld and Racing games be faster due it's specialized set of tool made specific for those needs.

## What is Formula LUAU?

Formula LUAU is a Roblox Formula one style games designed to allow players to develop custom engines and Aero platforms for competition. With various options on the types of Vehicles that can be used and developed.
